# Microsoft Copilot Studio — Professional Course

**From complete beginner to professional Copilot Studio agent developer.** This self-paced, documentation-verified course teaches you to design, build, configure, test, publish, govern, and operate AI agents with **Microsoft Copilot Studio**.

> [!IMPORTANT]
> **Current as of 18 November 2026.** Copilot Studio changed significantly in 2026: agents and workflows now run on **harnesses** (Microsoft Copilot, Customer Conversation, and standard). This course is built around that model and labels every feature's status. Microsoft ships updates monthly, so always check [What's new in Copilot Studio](https://learn.microsoft.com/en-us/microsoft-copilot-studio/whats-new).

## Who this course is for

| You are… | You'll learn to… |
|---|---|
| A **beginner** or business user | Understand AI agents and build your first useful agent without code |
| A **maker** or Power Platform developer | Design conversations, ground agents in knowledge, add tools, test, and publish |
| An **IT pro, admin, or CoE lead** | Secure, govern, monitor, and manage cost and capacity for agents at scale |
| A **solution architect** | Choose harnesses, design multi-agent and enterprise architectures, plan environments and ALM |
| A **job seeker** | Prepare with 300+ interview questions, ten projects, and a scored capstone |

**Scope:** this phase focuses exclusively on Microsoft Copilot Studio. Power Platform concepts are taught only where needed. There are no dedicated Power Automate, .NET, Azure development, or external API integration tracks.

## Before you start

- **Account:** a work or school account. Personal email addresses can be rejected at Copilot Studio sign-up.
- **Access:** a Copilot Studio trial is enough for most early labs, but **a trial can't publish agents**. Publishing labs need a license or pay-as-you-go access arranged by your admin. See [Module 03](03-Environment-and-Setup/README.md).
- **Cost awareness:** on the **Microsoft Copilot harness**, building, testing, and evaluating agents consume **Copilot Credits** from build time. Standard harness billing starts after publish. Labs flag any step that may consume credits.
- **Browser:** Microsoft Edge or Chrome 122+, Firefox 127+, or Safari 17+.
